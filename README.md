# Geosite2Surge
Geosite to Surge rule converter

Upstream: https://github.com/v2fly/domain-list-community

## Usage
```
geosite:google
RULE-SET,https://raw.githubusercontent.com/Luan-X/Geosite2Surge/refs/heads/generated/data/google,PROXY
geosite:xxxxxx
RULE-SET,https://raw.githubusercontent.com/Luan-X/Geosite2Surge/refs/heads/generated/data/xxxxxx,PROXY
```
